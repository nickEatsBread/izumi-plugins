# Guide for AI coding agents

This repository is izumi's plugin marketplace: listings that pin commits of other people's
repositories, the checks that run on them, and the generated `store.json` izumi reads. It holds no
plugin code apart from izumi's own plugins in `official/`, which are listed like any other. Read
`README.md` first.

## Which guide to follow

- Helping someone **build a plugin** (a feature that runs in izumi's plugin sandbox):
  `docs/building-a-plugin.md`. The plugin lives in its author's own repository, not here.
- Helping someone **build a source** (finds titles and streams; a signed `.izumi-ext` package):
  `docs/building-a-source.md`. It lives in its author's own repository too.
- Helping someone **build a pack**: `docs/building-a-pack.md`.
- Helping someone **get listed**: add `plugins/<id>/listing.json`, `sources/<id>/listing.json` or
  `packs/<id>/listing.json` as in `docs/listing.md`, run `npm run build` then `npm test`, and open a
  pull request using `.github/pull_request_template.md`.
- Changing **izumi's own plugins**: edit `official/<name>/`, run `node scripts/pin-main.mjs
  official/<name>` after changing its main file, and open a pull request. The hourly job moves its
  listing's pin once the change is on `main`.
- Helping someone **run their own marketplace**: `docs/running-a-marketplace.md`.
- A **theme** on its own goes to https://github.com/nickEatsBread/izumi-themes, not here.

## Rules

- Never edit `store.json` or `packs/<id>/pack.json` by hand. They are generated by
  `npm run build` (and by the update job).
- A listing's `commit` is a full 40-character SHA, never a branch or tag name.
- Never change a source listing's `signingKey` to make a check pass. A changed key needs a
  maintainer's review in its own pull request. The same goes for a plugin asking for different
  permissions.
- Never weaken a check in `scripts/lib.mjs` to get a listing through. It mirrors izumi's plugin
  runtime (`src/lib/plugins/manifest.ts` in https://github.com/nickEatsBread/izumi), package
  installer (`src-tauri/src/extension_package.rs`) and pack format (`src/lib/packs/format.ts`);
  change it only to follow a change there.
- Keep the virus scan a hard gate: a scan that fails to run is a failure, not a pass.
- Only list content its users are entitled to watch (see "What gets accepted" in the README).
- Never add "Generated with Claude Code", "Generated by Claude Code", a 🤖 footer, a co-author
  trailer for an AI tool, or a claude.ai session URL to commit messages, pull requests, issues,
  comments or code.

## Commands

```sh
npm install
npm test                        # unit tests, then every listing at its pinned commit
npm run build                   # regenerate store.json and pack copies; record new signing keys
node scripts/pin-main.mjs <dir> # write a plugin's main file hash into its plugin.json
node scripts/build.mjs --scan   # also run ClamAV (needs clamscan)
GITHUB_TOKEN=… node scripts/update.mjs --scan   # what the hourly job runs
```

Node.js 22.16 or newer. The only dependency is `fflate` (ZIP reading).
