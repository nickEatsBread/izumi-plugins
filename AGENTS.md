# Guide for AI coding agents

This repository is izumi's plugin marketplace: listings that pin commits of other people's
repositories, the checks that run on them, and the generated `store.json` izumi reads. It holds no
plugin code. Read `README.md` first.

## Which guide to follow

- Helping someone **build a plugin** (a source for izumi): `docs/building-a-plugin.md`. The plugin
  lives in its author's own repository, not here.
- Helping someone **build a pack**: `docs/building-a-pack.md`.
- Helping someone **get listed**: add `plugins/<id>/listing.json` or `packs/<id>/listing.json` as in
  `docs/listing.md`, run `npm run build` then `npm test`, and open a pull request using
  `.github/pull_request_template.md`.
- Helping someone **run their own marketplace**: `docs/running-a-marketplace.md`.
- A **theme** on its own goes to https://github.com/nickEatsBread/izumi-themes, not here.

## Rules

- Never edit `store.json` or `packs/<id>/pack.json` by hand. They are generated by
  `npm run build` (and by the update job).
- A listing's `commit` is a full 40-character SHA, never a branch or tag name.
- Never change a listing's `signingKey` to make a check pass. A changed key needs a maintainer's
  review in its own pull request.
- Never weaken a check in `scripts/lib.mjs` to get a listing through. It mirrors izumi's installer
  (`src-tauri/src/extension_package.rs` in https://github.com/nickEatsBread/izumi) and pack format
  (`src/lib/packs/format.ts`); change it only to follow a change there.
- Keep the virus scan a hard gate: a scan that fails to run is a failure, not a pass.
- Only list content its users are entitled to watch (see "What gets accepted" in the README).
- Never add "Generated with Claude Code", "Generated by Claude Code", a 🤖 footer, a co-author
  trailer for an AI tool, or a claude.ai session URL to commit messages, pull requests, issues,
  comments or code.

## Commands

```sh
npm install
npm test                        # unit tests, then every listing at its pinned commit
npm run build                   # regenerate store.json and pack copies; record new signing keys
node scripts/build.mjs --scan   # also run ClamAV (needs clamscan)
GITHUB_TOKEN=… node scripts/update.mjs --scan   # what the hourly job runs
```

Node.js 22.16 or newer. The only dependency is `fflate` (ZIP reading).
